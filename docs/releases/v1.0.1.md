# TinyTodo 1.0.1

## 本版变化

- 菜单栏图标 **左键点击直接展开/隐藏待办窗口**，可以立刻开始记录或勾选；右键（或 Control+点击）打开菜单。
- 菜单仍保留：今日完成数、快速添加、历史记录、设置、退出。
- 其余行为与 1.0.0 一致。

## 安装

1. 打开 `TinyTodo-1.0.1.dmg`，把 **TinyTodo** 拖进 Applications。
2. 从菜单栏图标左键点击，或 `⌥⇧T` 唤出窗口。
