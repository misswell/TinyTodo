# TinyTodo 1.2.1

## 菜单栏数字 = 剩余待办数

状态栏图标上的数字现在表示**还剩几项待办**，不是今天完成了几项。

- 实测：2 项未完成 + 1 项已完成 → 图标显示 `2`；把待办全部勾完后数字消失。
- 1.1.0 及更早版本的图标显示的是今日完成数，本次已修正。
- 设置 › 窗口行为可以关闭菜单栏计数。

## 边距与排版

- 顶栏高度 38 pt，中间的「已完成 / 今日任务」进度独立居中，不再被右侧图标挤压。
- 左/右统一 14 pt 边距；待办行上下留白 5 pt，悬停圆角 7 pt，长标题行高更舒服。
- 输入栏、标签栏、历史页的间距一并放大，整体更透气。

## 升级

- 正在使用 1.1.0 / 1.2.0：设置 › 更新 › 检查更新，或等启动时的自动检查。
- 仍在 1.0.x：需要手动安装一次本 DMG（1.0.x 没有更新组件）。

Developer ID 签名、Hardened Runtime、公证并 staple，Gatekeeper 直接放行；universal（arm64 + x86_64），macOS 14+。
