# TinyTodo 1.4.0

今天完成的待办不再立即消失。

- 完成当天任务后，条目会留在待办列表原位置。
- 完成的条目显示实心勾选、删除线，并变淡。
- 再次点击勾选可撤销完成，回到原来的排序位置。
- 次日进入应用时，昨天完成的条目自动移出待办列表，历史记录仍永久保留。
- Mac 和 iOS 使用同一套行为；菜单栏角标仍只统计未完成待办。

本次发布包含 138 个单元/集成测试，全部通过。
