# TinyTodo 1.1.0

## 新增：在线更新

设置 › 更新（或菜单栏右键 › 检查更新…）会检查 GitHub 的 `releases/latest`，发现新版本后可一键下载安装。

- 下载后校验：Release 记录的 SHA-256、bundle id、版本号、Developer ID 团队 `U8U443D7ZL`、designated requirement（保证辅助功能授权不丢）、Gatekeeper/公证。
- 安装由应用内的 `update-helper.sh` 完成：等待旧进程退出 → 备份 → 替换 `/Applications/TinyTodo.app` → 去 quarantine → 重新启动。
- 仅在 `/Applications` 内运行时自动更新；其他位置（Downloads、挂载的 DMG、开发构建）会提示手动下载。
- 启动时自动检查一次（可在设置关闭）；失败不打扰，只记录在更新面板。

> 1.0.x 没有更新组件，升级到 1.1.0 需要手动安装本 DMG；从 1.1.0 起可在应用内收到后续更新。
