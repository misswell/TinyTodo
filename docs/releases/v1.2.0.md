# TinyTodo 1.2.0

## iCloud 存储

设置 › 数据 › **使用 iCloud Drive…** 选择一个 iCloud Drive 文件夹，TinyTodo 会把 `TinyTodo.sqlite`
放在那里，由 iCloud 同步到其他 Mac。

- 切换时如果 iCloud 文件夹里已有数据库，会让你选择「使用 iCloud 数据」或「用本机数据覆盖」。
- 切回本机存储会把 iCloud 数据复制回来，并把原本机库保留为带时间戳的备份。
- iCloud 模式使用单文件回滚日志（`journal_mode=DELETE`、`synchronous=FULL`），避免 WAL 旁文件影响同步。
- 切换后需要重启 TinyTodo。
- iCloud 是文件级同步，不做逐条冲突合并；建议同一时间只在一台 Mac 上编辑。

## 菜单栏剩余数量

状态栏图标现在显示**剩余待办数**（此前是今日完成数）；菜单仍同时列出待办和今日完成。
设置 › 窗口行为可以关闭菜单栏计数。
