# TinyTodo 1.3.0 — Mac + iOS 同一个代码库

## macOS（1.3.0）

- **待办按日期分组**：和「历史」一致的节奏，「今天 · 11月19日 2 项」「昨天 · 11月18日」「11月13日 星期五」，最近一天在最上面。组内拖动只影响当天。
- 输入框草稿自动保存并回显；输入过长自动换行增高（最多 4 行，面板同步增高）。
- 菜单栏图标显示剩余待办数；左键在图标下方展开面板，右键出菜单。
- 应用内在线更新（校验 SHA-256、版本、Developer ID 团队、designated requirement、公证）。
- iCloud Drive 存储：可选与 iOS 相同的文件夹，两台设备读写同一个数据库。

## iOS（1.0.0，随仓库一起发布）

- 源码位于 `TinyTodoIOS/`，与 `Shared/` 里的数据层一起编入工程；Xcode 打开 `TinyTodo.xcodeproj` 选 **TinyTodoIOS** 即可运行。
- 待办按创建日期分组、底部单行快速记录（1–4 行自动增高）、历史搜索、左滑恢复 / 右滑删除、累计完成数。
- 设置 › 同步：用系统文件选择器挑一次 iCloud Drive 里的 `TinyTodo` 文件夹（security-scoped bookmark），也能改回本机存储。

```bash
xcodebuild -project TinyTodo.xcodeproj -scheme TinyTodoIOS \
  -destination 'platform=iOS Simulator,name=iPhone 17 Pro' build
```

iOS 端不在 App Store：分发需要单独的应用记录、证书与审核，仓库里只提供源码与构建方式。
模拟器测试运行器在本机执行时会卡在 “test runner hung before establishing connection”，因此没有把
会卡住的测试配置留在工程里；共享数据层由 macOS 套件的 130 个测试覆盖。

## 安装（macOS）

打开 `TinyTodo-1.3.0.dmg`，拖进 Applications。Developer ID 签名、公证并 staple，Gatekeeper 直接放行；
universal（arm64 + x86_64），macOS 14+。
