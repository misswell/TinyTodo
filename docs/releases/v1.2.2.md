# TinyTodo 1.2.2

## 修复：输入框垂直错位

之前占位文字是 SwiftUI 的 `Text`（12.5 pt，无内边距），输入文字是 `NSTextView`（13 pt，顶部 4 pt 内边距），
两套排版各算各的基线，所以看起来一高一低。

现在占位符由**同一个 `NSTextView`** 在自己内部绘制：

- 与输入文字共用 13 pt 字体、同一 `textContainerInset`、同一条基线；
- 行高由 `VerticalTextLayout.insetY(containerHeight:lineHeight:)` 计算，输入区域高度变化时自动重新居中；
- 实测：+ 图标中心 y=810.0，占位文字中心 y=810.5（2× 像素截图上量取），打字后文本原点不变（单元测试断言）。
