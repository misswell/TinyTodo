# TinyTodo 1.2.4

## 待办也按日期分组

待办列表现在和「历史」一样按日期分隔：

- 组头显示「今天 · 11月19日 2 项」「昨天 · 11月18日」「11月13日 星期五」，最近的一天在最上面。
- 组内仍可拖动排序；拖动只影响当天，其他日期不会被挤乱。
- 分组依据是**创建日期**（历史页用的是完成日期），所以待办出现在你写下它的那一天下面。

## 新增 iOS 端（1.0.0）

同一个仓库里加入了 iOS App（`TinyTodoIOS`）：

- 待办按日期分组、单行快速记录、历史搜索、左滑恢复/删除、右滑删除。
- 与 Mac 共用同一套 SQLite 结构与 JSON 备份格式（`Shared/`）。
- 设置 › 同步里用系统文件选择器挑一次 iCloud Drive 中的 `TinyTodo` 文件夹，两台设备就读写同一个数据库；也能随时切回本机存储。

> iOS 端需要 Xcode 安装 iOS 平台组件后才能在模拟器运行；当前机器上该组件仍在下载。
