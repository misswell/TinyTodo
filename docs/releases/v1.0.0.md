# TinyTodo 1.0.0

原生 macOS 悬浮待办小窗口：打开就能看到、一次输入回车记录、一次点击完成，历史永久保留。

## 安装

1. 打开 `TinyTodo-1.0.0.dmg`，把 **TinyTodo** 拖进 Applications。
2. 从菜单栏图标或 `⌥⇧T` 唤出窗口。
3. 首次启动会在 `~/Library/Application Support/TinyTodo/` 创建本地 SQLite 数据库；不联网、无账号。

## 本版内容

- AppKit `NSPanel` 悬浮面板：置顶、跨 Spaces、全屏辅助、失焦不隐藏、逐显示器记忆位置
- 一次输入 + Enter 记录，支持多行粘贴拆条；拼音候选词确认不会误提交
- 单击完成进入历史，⌘Z / Toast 撤销；历史按天分组、按月、搜索、恢复、删除
- SQLite（GRDB）WAL + v1→v3 迁移，历史永不自动清理；JSON 导入导出
- 菜单栏、全局快捷键、开机启动、深色/浅色、窗口透明度
- 79 个单元/集成测试；XCUITest 覆盖启动/创建/完成/历史/设置

- 不含 iCloud、提醒、子任务、标签、AI 功能（首版范围）
