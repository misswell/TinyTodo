# TinyTodo 1.2.3

## 修复：1.2.2 安装包版本号不对

1.2.2 的 DMG 里，`TinyTodo.app` 的 `CFBundleShortVersionString` 实际还是 **1.2.1**。原因是只改了
`project.yml` 的版本号，没有重新生成工程。应用内更新检查拒绝它是正确的，但发出去的包是错的。

- `scripts/release.sh` 现在自己执行 `xcodegen generate`，并在签名前断言产物版本与 `project.yml`
  一致，不一致立即失败。
- 更新校验把「版本不匹配」单独报出来并提示可能是发布时没重新生成工程。

## 新增：输入框草稿缓存

写到一半的待办不会再丢：

- 每次输入都会写入本地偏好，隐藏窗口、退出应用、程序崩溃后重新打开，输入框原样回显。
- 只有真正提交（Enter）后才清除草稿。
- 实测：写入草稿后重启应用，输入框内容完整恢复。

## 新增：超长输入自动换行增高

- 输入变长时输入框自动换行并增高，最多 4 行，再多则内部滚动。
- 面板会同步向下增高，标签栏始终可见；`+` 图标固定在第一行左侧。
- 实测：3 行草稿让面板从 460 pt 增高到 504 pt。
